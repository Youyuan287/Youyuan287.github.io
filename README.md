# Youyuan Tang — Academic Homepage

This folder contains a ready-to-deploy bilingual academic homepage for Youyuan Tang (唐友源).

## Files

- `index.html`: complete bilingual Chinese/English homepage.
- `assets/profile.jpg`: personal photo placeholder path. Put your photo here using this exact filename.

## Quick start

Open `index.html` directly in a browser to preview the homepage.

For GitHub Pages, upload the contents of this folder to the root of your `username.github.io` repository and enable GitHub Pages.
